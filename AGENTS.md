# Project Agent Rules for GPU4PySCF Excited State & Multireference Project

## Knowledge Base Synchronization Rule

Whenever theory, mathematical formulations, GPU algorithmic strategies, or software architecture decisions are discussed, clarified, derived, or decided upon in conversation:

1. **Active Documentation:** You must systematically curate and update the corresponding modules in `knowledge_base/` using the guidelines in `.agent/skills/knowledge-base-curator/SKILL.md`.
2. **Preserve & Link:** Do not delete existing established content; integrate new insights, formulas, derivations, and code prototypes into the appropriate module (`01_` through `08_`).
3. **Index & Status Maintenance:** Always ensure `INDEX.md` and `08_codebase_gap_analysis_and_phase1_plan.md` reflect the latest state of knowledge and implementation roadmap.
